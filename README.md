# anshroshan.com — portfolio

Personal portfolio of Ansh Roshan — AI Engineer. Next.js 16 (App Router,
Turbopack), React 19, Tailwind v4, GSAP/Framer Motion driven UI.

The blog lives in a separate repo (`AnshRoshan/blog`, an Astro static site at
[blog.anshroshan.com](https://blog.anshroshan.com)); the nav links there
directly. Each project ships under its own `*.anshroshan.com` subdomain; this
site is the hub at the apex domain.

## Getting Started

```bash
bun install   # or npm install
bun dev       # or npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
bun run lint        # biome check --write (format + autofix)
bun run typecheck   # tsc --noEmit
bun run check       # lint + typecheck, no writes
bun run build       # production build
```

## Structure

- `src/app/` — routes: home, about, projects (+ `/projects/[slug]` case
  studies), contact; `robots.ts`, `sitemap.ts`, `manifest.webmanifest`,
  `api/og` (dynamic Open Graph images)
- `src/config/site.ts` — single source of truth for name, URL, description,
  keywords and social links; everything SEO-related derives from it
- `src/lib/seo.ts` — `pageMetadata()` (canonical + OG/Twitter per page) and
  schema.org JSON-LD builders (Person, WebSite, CreativeWork, BreadcrumbList)
- `src/components/seo/json-ld.tsx` — renders the structured data scripts
- `src/components/main/` — site sections (hero, nav, projects, footer)
- `src/components/sub/` — small motion/UI primitives
- `src/components/ui/` — shadcn-style primitives
- `src/data/` — single source of truth for projects & skills
- `scripts/to-webm.mjs` — video conversion helper for background assets

## SEO checklist (what's wired up)

- Per-page canonical URLs and unique titles/descriptions via `pageMetadata()`
- Absolute Open Graph + Twitter card images on every route (generated by
  `/api/og`, long-cached)
- JSON-LD: `Person` + `WebSite` sitewide, `CreativeWork` + `BreadcrumbList`
  on each project page
- `sitemap.xml` includes all static routes and every project detail page
  (auto-grows from `src/data/projects.ts`); `robots.txt` points at it and
  explicitly allows `/api/og` for crawlers
- PWA manifest with real icons; `lang`, theme-color, and pre-paint theme
  script set in the root layout

When adding a project: append to `src/data/projects.ts` — the detail route,
sitemap entry, metadata, and JSON-LD all follow automatically.
